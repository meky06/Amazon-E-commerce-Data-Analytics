# Amazon-E-commerce-Data-Analytics

Demo Amazon E-commerce analytics project using **SQL and Power BI** to analyze sales, customers, products, and delivery performance.

## Project Overview

This project analyzes the **Brazilian E-Commerce Public Dataset by Olist** to uncover insights into sales performance, customer behavior, product performance, and delivery operations.

The project combines SQL and Power BI to transform raw e-commerce data into an interactive and insightful dashboard.

## Business Objectives

* Analyze revenue and sales trends over time
* Identify top-performing product categories
* Understand customer purchasing behavior
* Analyze delivery performance and late deliveries
* Identify customer purchasing patterns
* Demonstrate how data analytics can support business decisions

## Tools

* **SQL Server / SSMS** — Data validation, data preparation, table generation, and data analysis using SQL queries and aggregate functions
* **Power BI** — Data modeling, DAX, and interactive visualization
* **GitHub** — Project documentation and version control

## Dashboard

### Overview

Provides a high-level view of the e-commerce business, including revenue, orders, customers, and delivery performance.

### Trend Analysis

Analyzes how sales and order activity change over time to identify trends and seasonality.

### Product Analysis

Explores best-selling and most frequently ordered product categories.

### Customer Analysis

Examines customer purchasing behavior and identifies patterns in customer activity.

### Delivery Analysis

Analyzes delivery performance, delivery times, and late deliveries to identify operational patterns.

## Key Focus

The dashboard demonstrates how **SQL-based data preparation and Power BI visualization** can be combined to transform raw e-commerce data into actionable business insights.
